# SHINE TECH - Smarter Tech. Brighter You.

A high-performance electronics e-commerce marketplace inspired by Flipkart's shopping experience with a unique, original dark navy and electric blue brand identity.

---

## ⚡ Tech Stack
- **HTML5**: Semantic, accessible markup with meta tags and SEO optimization.
- **CSS3**: Custom design tokens, responsive CSS grid/flexbox layouts, micro-animations, glassmorphism touches, and mobile drawers. No heavy CSS frameworks.
- **Vanilla JavaScript (ES6+)**: Fast, lightweight client-side catalog searching, filtering, local storage persistence for cart and wishlist, live autocomplete, and modals.
- **Run Target**: Designed for VS Code Live Server (zero server or Node.js runtime required).

## 🚀 How to Run with VS Code Live Server
1. Open the project folder (`Shine Tech`) in **VS Code**.
2. Make sure you have the **Live Server** extension by Ritwick Dey installed.
3. Right-click on `index.html` and select **"Open with Live Server"** (or click "Go Live" at the bottom right status bar).
4. The website will open at `http://127.0.0.1:5500/index.html`.
